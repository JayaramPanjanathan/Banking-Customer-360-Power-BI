# Banking Customer 360 Power BI Project

## Project Overview

This portfolio project shows how customer, account, loan, branch, merchant, card, and transaction data can be connected to create a Banking Customer 360 reporting view.

The project uses synthetic banking data downloaded from Kaggle. No employer, customer, or company data is included.

## Business Problem

Banking data is often stored across separate tables and systems. This can make it difficult to understand the full customer relationship across accounts, loans, cards, branches, merchants, and transactions.

## Project Goals

- Build a clear banking data model
- Connect customers with accounts, loans, cards, and transactions
- Create a Power BI Customer 360 dashboard
- Analyze customer and product relationships
- Review data quality and table relationships
- Document the model, measures, and reporting logic

## Tools Used

## Dataset

This project uses a publicly available synthetic banking dataset from Kaggle.

Main files include:

- Customers
- Accounts
- Loans
- Branches
- Cards
- Merchants
- Transactions

## Planned Dashboard Pages

### 1. Customer 360 Overview

- Total customers
- Total accounts
- Total account balance
- Total loans
- Total transactions
- Average transaction amount

### 2. Customer and Product Relationships

- Customers by account type
- Customers holding multiple products
- Loan customers with and without deposit relationships
- Product relationships by branch

### 3. Transaction Analysis

- Monthly transaction trends
- Transactions by merchant
- Average transaction amount
- High-value transaction analysis

## Data Privacy

This project uses synthetic public data only.

No confidential customer, employer, or company data is included.
